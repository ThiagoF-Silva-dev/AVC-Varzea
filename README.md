# ⚽ Sistema de Gestão para Futebol Amador (AVC)

Repositório desenvolvido como parte da **AVC (Atividade de Validação Conectada)** da disciplina de **Lógica de Programação**. O projeto consiste em um sistema em **Python** voltado para o gerenciamento de campanhas, estatísticas de partidas e controle de um time de futebol amador (futebol de várzea).

---

## 🚀 Funcionalidades

* **Gestão de Partidas:** Registro de resultados, gols, cartões e desempenho dos jogadores.
* **Controle de Elenco:** Cadastro e acompanhamento dos atletas do time.
* **Estatísticas da Campanha:** Acompanhamento de pontos, vitórias, empates, derrotas e saldo de gols.
* **Lógica Aplicada:** Uso de estruturas condicionais, laços de repetição e manipulação de dados em Python.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Ambiente de Desenvolvimento:** PyCharm / VS Code
* **Controle de Versão:** Git e GitHub
